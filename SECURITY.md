# Politica de seguridad

Mientras el proyecto este en 0.x, las correcciones se publican sobre la ultima version.

No abras un issue publico ni incluyas certificados, claves, CUIT, tokens, tickets WSAA o respuestas productivas. Usa GitHub Security Advisories en el repositorio donde se publique el proyecto e incluye version, impacto y reproduccion minima anonimizada.

Una credencial publicada debe revocarse y rotarse. Borrarla del ultimo commit no la elimina del historial.

La guia operativa esta en docs/seguridad.md.
