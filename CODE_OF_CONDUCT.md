# Codigo de conducta

Este proyecto adopta el Contributor Covenant 2.1.

Participa con respeto, buena fe y foco tecnico. No se toleran acoso, discriminacion, amenazas, publicacion de datos privados ni ataques personales.

Los mantenedores pueden moderar contenido y restringir participacion para proteger a la comunidad. Reporta incidentes de conducta por un canal privado del mantenedor.

Referencia: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
